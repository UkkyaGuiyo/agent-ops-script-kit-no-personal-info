# 容量見張り係：技術仕様（PILOT）

**目的:** 明示されたフォルダの通常ファイルの見かけ上の大きさを合計し、設定したしきい値と比較する。単位は **bytes**。

**入力:** JSONの `targets` 配列。各対象は一意の `name`、`path`、非負整数の `warning_bytes` を必須とする。相対パスは設定ファイルの場所から解決する。

**出力:** stdoutへJSON。正常時 `status=ok`、対象ごとに `name`, `bytes`, `warning_bytes`, `warning`, `files`, `skipped_symlinks`。しきい値以上で `warning=true`。失敗時 `status=error`、終了コード2であり、途中までの値を正常な計測値として表示しない。

**起動:** 手動CLIのみ。スケジューラーや常駐サービスは搭載しない。

**処理:** 設定の型と値を検証し、対象が実際のディレクトリか確認。パスの途中も含め、シンボリックリンクは拒否・スキップする。通常ファイルのサイズだけを合計する。

**失敗:** 不正JSON、欠落したディレクトリ、読み取り不能、途中で消えたファイル、走査失敗はエラー。失敗を空の結果に変換しない。

**重複と再試行:** 読み取り専用なので再実行可能。ただし走査中のファイル変更による不一致はありうる。

**権限:** ローカルフォルダへの読み取り・探索権限のみ。ネットワーク・外部アカウント・管理者権限は不要。

**制限:** ディスクの空き容量・実際の物理割当量は測定しない。ハードリンクが複数のパスにある場合は重複計上しうる。特殊ファイルは除外。動くフォルダの原子的スナップショットではない。

**停止と復旧:** コマンドを終了するだけ。対象ファイルは変更しない。

**検証:** 合成データの自動試験あり。独立した実環境検証はPENDING。
