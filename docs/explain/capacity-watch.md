# 容量見張り係を初心者に説明する

**何をする係？** 指定したフォルダに置かれた普通のファイルの大きさを合計し、決めた数字を超えたか知らせる。

**なぜスクリプト？** AIに毎回数え方から考えてもらう代わりに、決めた手順を同じように実行するため。

**何が楽になる？** フォルダの大きさと基準値を見比べる作業。定期実行はまだ搭載していない。

**どこが危ない？** 間違ったフォルダを調べると役に立たない。権限不足などで途中で調べられなければエラーになる。ディスクの空き容量を測るものではない。シンボリックリンクはたどらない。

**何を人間が決める？** 調べる場所、警告する大きさ、いつ使うか。ファイルの削除はしない。

MuseなどのAIが説明する際は、実行していない結果を「問題なし」と言わないこと。自分にPC操作の手段がなければ、導入手順の説明に留める。
